AI를 다루는 방식

모델 출력은 믿지 않고 검증한다팩트체크는 tool use로 구조화 출력을 강제하고, 결과 마커가 없으면 FAIL. 영상 클립은 비전 모델로 QC해 문제 비트만 재생성. 답변에는 검색 근거 각주를 붙입니다.
모델은 실측으로 고른다영상 모델 4회 교체, 대본 모델 Gemini→Claude 복귀, 이미지 단가 $0.211→$0.053. 품질·단가·쿼터를 숫자로 비교해 결정하고 버린 코드는 지웁니다.
사람이 끼어드는 지점을 설계한다텔레그램 3단계 검수, 승인 없으면 발송되지 않는 소셜 리스닝, 검증만 하는 리드 웹앱. 자동화 범위와 사람 승인 지점을 먼저 정합니다.
안 되면 숫자로 접는다마케팅 실험 셋은 기술은 돌았지만 유입이 없었습니다. 편당 비용·생성 건수·트래픽을 보고 멈췄고, 거기서 만든 팩트체크·비용 원장·큐 설계는 사내 서비스로 가져갔습니다.
비용은 원장으로 관리한다편당·장당 단가를 기록하고 월 상한 가드를 둡니다. 광고 자동화 월 $37–67, Lead-Crawler 7월 API 비용은 예산의 22%.
프롬프트 경계를 지킨다사용자 데이터는 데이터 구간으로 격리해 인젝션을 막고, AI 는 질문한 사람의 권한 범위만 열람합니다. 외부 호출은 provider 모듈 한 곳으로만 나갑니다.
키 없이도 전 구간이 돈다모든 AI 파이프라인에 dry-run을 기본값으로 두었고, CI는 실키 없이 끝까지 재현합니다.

문제
신생 브랜드라 쇼핑몰로 사람을 데려올 장치가 필요했습니다.
해결
로그인 없이 바로 써 보는 게스트 체험을 앞에 두었습니다. 크레딧은 쇼핑몰 연동 +3, 주문 +20을 줘서 연동과 구매로 이어지게 했습니다.
결과

해결
수집은 크롤러가 하고 사람은 검증만 합니다. 운영비 상한은 월 50만 원으로 두고 원장으로 관리했습니다. 2026년 7월 API 비용은 예산의 22%였습니다.

  • 쿼리 병목 추적. EXPLAIN ANALYZE로 정렬 키의 상관 서브쿼리가 24,470번 실행되는 걸 찾아 LEFT JOIN으로 바꿨습니다. 회귀 테스트 150개 통과를 확인했습니다.

  • 무인 운영. 연속 크롤 모드, 좀비 프로세스 워치독, 재시작 후 잡 자동 재개, 월 예산 가드, Notion 일일보고 자동 작성까지 갖췄습니다.

2026.07 – 09백엔드 전담 · 2인 팀(프론트 1)

SNS와 커뮤니티에서 키워드 게시글을 감지해 모으고, 사람이 승인해야만 답글이 나가는 소셜 리스닝 도구.

문제
처음 요청은 댓글을 자동으로 뿌리는 봇이었습니다. 플랫폼 약관 위반, 스팸, 여론조작 위험이 컸습니다.
해결
사람 승인형으로 범위를 다시 정하고 요청자와 합의했습니다. 자동 발송 경로는 코드에 아예 만들지 않았습니다.
